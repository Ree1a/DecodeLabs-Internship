 Number Guessing Game 
A robust Java-based CLI application developed as part of the DecodeLabs Internship. This project is an interactive number guessing game that challenges the user to guess a randomly generated number within a specified range.

## Features
* **Dynamic Range Selection:** Random number generation between a custom range (1-100).
* **Limited Attempts:** Adds excitement by restricting the number of trials per round.
* **Score Tracking:** Displays the user's score based on their performance and attempts taken.
* **Play Again Option:** Allows players to start multiple rounds seamlessly without restarting the app.

## Technologies Used
* **Language:** Java (JDK 11+)
* **Core Concepts:** Loops, Conditional Statements, Random Class, Scanner for User Input.

##  How to Run
1. Clone the repository.
2. Compile the Java file: `javac Game_P1.java`
3. Run the application: `java Game_P1`
